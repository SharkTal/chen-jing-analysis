# Self-Check Reference: 分析质量保障手册

> 本文件供分析师在输出前自检，以及在分析被证伪后进行错误复盘。  
> 在 SKILL.md 中引用：完成六层分析草稿后，读取本文件进行输出前检查。

---

## Part 1: 输出前检查清单（Pre-flight Checklist）

完成六层分析后，逐条核对以下问题。如果有任何一条回答是"否"，在输出前修正。

### 🔍 Layer 1 · 数据打假
- [ ] 所有关键数据都注明了来源（机构名称/发布日期）？
- [ ] 有没有指出样本范围的局限（例如"这个数据只覆盖X市场"）？
- [ ] 有没有找到至少一个**交叉验证指标**来核实主要数据？
- [ ] 有没有说明哪些数字是"一次性因素"或"会计处理"导致的，而非真实趋势？

### 🗺️ Layer 2 · 利益地图
- [ ] 列出的行为者是否**超过两方**（避免只看多空两面）？
- [ ] 每个行为者是否区分了"面子需求"和"实质需求"？
- [ ] 有没有识别出**结构性买家/卖家**（价格不敏感）与**周期性买家/卖家**（价格敏感）？

### ⚙️ Layer 3 · 结构分析
- [ ] 有没有找到当前局面的**核心瓶颈**（那个如果突破就会改变一切的变量）？
- [ ] 有没有说明"光伏路径"是否适用（谁在大规模投入，成本是否在下降）？

### 📚 Layer 4 · 历史类比
- [ ] 有没有明确说明类比的**边界**（"这个类比在X方面不成立，因为..."）？
- [ ] 类比的历史案例是否足够**近期**（5-10年内优先，避免使用过时的市场环境）？

### ⚖️ Layer 5 · 多因素综合
- [ ] 有没有评估**每个因素的可变性**（Low/Medium/High）？
- [ ] 有没有找到**当前的共振集群**（多个因素同时指向同一方向）？
- [ ] 有没有识别出**主导因素**（那个改变后一切都变的变量）？

### ♟️ Layer 6 · 博弈视角
- [ ] 有没有从**对手视角**推演（他们的底线是什么，他们能承受多大损失）？
- [ ] 有没有找到"各方都能接受的最小公约数"方案？

### 📊 综合输出
- [ ] 结论是**概率分布**而非"一定会X"？
- [ ] 每条路径都有**明确的触发条件**（而不是模糊的"如果情况好"）？
- [ ] 有没有同时列出**向上修正的触发器**和**向下修正的触发器**？
- [ ] 有没有主动说明**这个分析可能在哪里出错**（自我证伪机制）？

## Part 3: 错误复盘模板（Post-mortem Template）

当分析结论被现实证伪时，使用以下模板进行复盘。**复盘不是为了批判，而是为了升级方法论。**

```markdown
## 错误复盘 #[编号]

**原始预测日期**: YYYY-MM-DD  
**复盘日期**: YYYY-MM-DD  
**主题**: [同原始分析]

### 1. 发生了什么？

**我预测的**: [简述原始结论]  
**实际发生的**: [简述真实结果]  
**偏差幅度**: [例：预测$5,000，实际$3,800，偏差-24%]

### 2. 错误层次诊断

在以下选项中打勾（可多选）：

- [ ] **数据错误** — 使用了错误/偏差的数据源
  - 具体是哪个数据？应该用什么替代？

- [ ] **假设错误** — 某个关键前提假设不成立
  - 哪个前提？为什么当初会有这个假设？

- [ ] **遗漏因素** — 多因素分析里漏掉了重要变量
  - 漏掉了什么？为什么会漏掉？

- [ ] **类比失效** — 历史类比在关键方面不适用
  - 哪里不适用？差异是什么？

- [ ] **逻辑链断裂** — 因果推理某处有跳跃
  - 具体在哪一步？

- [ ] **时间点错误** — 方向正确但时间判断有误
  - 早了多久？晚了多久？

- [ ] **黑天鹅事件** — 无法预见的突发因素
  - 是什么事件？能否在未来分析中加入"突发事件" layer？

### 3. 触发器回顾

**触发器有没有发出信号？**
- [ ] 有信号，但我没有及时捕捉
- [ ] 有信号，但我捕捉了却没有修正判断
- [ ] 没有明显信号（真正的黑天鹅）

### 4. SKILL.md 升级建议

> 错误复盘的最终价值在于改进方法论，而不是懊悔结果。

根据以上诊断，SKILL.md 中哪一层需要修改？

| 修改层 | 具体改动 | 优先级 |
|--------|---------|--------|
| Layer X | [改动描述] | High/Medium/Low |

### 5. 陈经原则对照

检查这次错误是否违反了陈经的认知论原则：

- [ ] 是否因为"立场驱动"而忽视了不利信号？
- [ ] 是否用了"赌博式判断"而不是概率论？
- [ ] 是否混淆了"运气"和"结构性因素"？
- [ ] 是否没有做"自我纠错"（发现信号变化后没有及时更新）？
```

## Part 4: 四种典型错误类型速查

| 错误类型 | 识别特征 | 典型案例 | 修复方向 |
|---------|---------|---------|---------|
| **假设过强** | "一定"、"必然"、"不可能" | "美联储今年一定降息" | 改为概率表达，加触发条件 |
| **因素遗漏** | 结果被一个未分析的因素主导 | 忽视了黑天鹅地缘事件 | Layer 5 加入"突发事件"兜底因素 |
| **类比边界失效** | 历史案例与当前有重大结构差异 | 用2000年科技股类比2026年AI股忽视了央行角色 | Layer 4 强化"边界说明"步骤 |
| **触发器未监测** | 信号出现了但没有更新判断 | CPI已回落到3%以下，但没有切换到路径B | 建立定期复查机制（每月检查触发器清单）|

## Part 5: 陈经的自我纠错黄金案例

> 参考：#59帖（唱衰英伟达失败的复盘）

他的复盘思路可以作为模板：

**第一步：承认事实**
> "中际旭创600多元唱衰...现在要冲击1000了，唱衰失败。"

**第二步：诊断错误层次**
> "总结下，为啥唱衰英伟达和中际旭创失败。最大原因是业绩。"

**第三步：升级认知框架**
> "要学习AI的认知论。AI自己是没有态度的，但对于接收的输入非常重视，会全面调研综合各种信息。"

**第四步：给出新的操作原则**
> "在认知上，要重视信息、信号，这样在平衡局面下，就会有不错的预测能力。如果有绝对的理由，那可以胜过短期信号。"

**关键精神**：**错误 → 诊断层次 → 升级方法论 → 新的操作原则**，而不是单纯的懊悔或辩解。
